# Divine Acquisition — conversion landing

Public marketing site for Divine Acquisition's cleaning-company install: AI booking, follow-up, and retention.

Live: [go.divineacquisition.io](https://go.divineacquisition.io)

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Magic UI (particles, marquee, magic card, border beam, shine border, number ticker)
- Coss-style DA panel surfaces (shared with the DA / Vistrial marketing sites)

## Development

```sh
npm install
npm run dev
```

Build:

```sh
npm run build
```
